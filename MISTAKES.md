# Mistakes

| Date | Topic | What I thought | Correct idea | Revised? |
|---|---|---|---|---|
| 2026-10-03 | 0.1 Git vs GitHub | GitHub is the tool you use to "apply" Git's rules, and it stores "different types of software" | Git = version control program on your laptop, works offline, tracks commits. GitHub = website that hosts Git repos (files + full history) online for backup and collaboration. You can use Git without GitHub. Commits are local, and GitHub only sees them after `git push`. | ✅ 2026-10-04 |
| 2026-10-03 | 1.1 javac / packages | Wrote `package phase-01-core-java;` (copied the folder name) | Package names follow identifier rules: letters, digits, `_`, `$` only, and can't start with a digit. `-` is the minus operator → compile error. Folder names can have `-`, package names can't. | ❌ |
| 2026-10-03 | Git: commit IDs | Thought the new commit ID was the old ID with characters "shifted" (+5, +1, +3) | A commit ID is a SHA-1 hash (fingerprint) calculated from: file snapshot + message + author + timestamp + parent. Change anything → completely different ID, no pattern. That's why `--amend` gives a new ID and you shouldn't amend pushed commits. | ❌ |
| 2026-10-03 | Git: .gitignore | Wrote `.*class` instead of `*.class` | `*` = "anything". `*.class` = any name ending in .class. `.*class` = names starting with a dot. | ❌ |
| 2026-10-03 | Git: 3 areas | Didn't name the areas. Thought area 3 = GitHub (via git push) | 3 areas are ALL local: Working Directory → (git add) → Staging Area → (git commit) → Local Repository (.git). `git push` copies to the remote (GitHub), which is NOT one of the 3 areas. Same Git-vs-GitHub confusion as earlier. | ✅ 2026-10-04 |
| 2026-10-03 | 1.2 main / JVM | "main is void because the JVM compiles the whole code" | `javac` compiles, the JVM only runs bytecode. main is void because when main ends the program ends, so nobody is there to receive a return value. Exit status is sent with System.exit(n). | ❌ |
| 2026-10-03 | 1.2 main / arrays | `java MainArgs apple mango` → said args[1] = apple | Arrays start at index 0: args[0] = apple, args[1] = mango. The class name is NOT in args. With no words, args is an empty array (length 0), not null. | ❌ |
| 2026-10-04 | 1.3 casting / overflow | `(byte) 130` → guessed 127, then -127, then -128 | Narrowing wraps around (no clamping at max). After 127 → -128, -127, -126... Shortcut: if > 127, subtract 256 → 130 - 256 = -126. | ❌ |
| 2026-10-04 | 1.3 primitives | Listed "integer" and "string" as primitives | 8 primitives (all lowercase): byte, short, int, long, float, double, char, boolean. `String` and `Integer` are classes (reference types). | ❌ |
| 2026-10-04 | Git: commit types | Used `feat:` for a rename, said `refactor:` for a new method | `feat:` = program can do something NEW. `fix:` = something broken now works. `refactor:` = code changes but behaviour is the SAME (rename, cleanup). `docs:` = notes/.md. Don't mix code + notes in one commit. | ❌ |
| 2026-10-04 | 1.3 default values | Thought an uninitialized local `int` prints nothing | Local variables have NO default → compile error "might not have been initialized". Only fields get defaults (0, false, null). | ❌ |
| 2026-10-04 | 1.4 operators | `i++` → said 6; `7/2` → 5; `-7 % 3` → couldn't; `x != 0 && 10/x` → "crashes"; `a != null \|\| a.isEmpty()` → "no crash" | `a = i++` gives old value (5). int/int cuts decimals (3). `%` takes sign of LEFT number (-1). `&&` skips right if left false; `\|\|` skips right only if left TRUE — `a != null \|\| a.isEmpty()` with null → NPE. Safe: `a == null \|\| a.isEmpty()`. | ❌ |
